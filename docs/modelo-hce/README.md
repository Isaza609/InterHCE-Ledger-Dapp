# Modelo de Historia Clínica Electrónica (HCE) para urgencias

Estructura mínima de HCE para el escenario de urgencias, basada en:

- Registro de Datos de Atención (RDA).
- Resoluciones regulatorias (Colombia).
- Estándares de interoperabilidad (HL7/FHIR donde aplique).

Este modelo es de referencia para creación, validación e interoperabilidad de episodios clínicos. **No se almacena en Blockchain**; solo hashes y metadatos no sensibles van on-chain.

Colocar aquí esquemas (JSON Schema u otro), campos obligatorios/opcionales y reglas de validación.
