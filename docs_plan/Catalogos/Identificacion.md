# Catálogo de Tipos de Documento de Identificación (Colombia)

| Código | Nombre                             | Descripción                                                                 |
|--------|------------------------------------|-----------------------------------------------------------------------------|
| CC     | Cédula de Ciudadanía               | Documento de identificación para ciudadanos colombianos mayores de edad     |
| TI     | Tarjeta de Identidad               | Documento para menores de edad en Colombia                                  |
| RC     | Registro Civil                     | Documento de identificación para recién nacidos                             |
| CE     | Cédula de Extranjería              | Documento para extranjeros residentes en Colombia                           |
| PA     | Pasaporte                          | Documento de identificación internacional                                   |
| PPT    | Permiso por Protección Temporal    | Documento para población migrante (ej. venezolanos en Colombia)             |
| PEP    | Permiso Especial de Permanencia    | Documento migratorio temporal (en proceso de transición a PPT)              |
| NIT    | Número de Identificación Tributaria| Identificación de personas jurídicas o naturales ante la DIAN               |
| NUIP   | Número Único de Identificación     | Número asignado desde el registro civil (base para CC/TI)                   |
| CD     | Carné Diplomático                  | Documento para personal diplomático acreditado                              |
| SC     | Salvoconducto                      | Documento temporal para extranjeros en tránsito o situación especial        |
| DE     | Documento Extranjero               | Tipo genérico para identificación extranjera no clasificada                 |
| AS     | Adulto sin Identificación          | Registro temporal en sistemas de salud                                      |
| MS     | Menor sin Identificación           | Registro temporal para menores sin documento                                |
