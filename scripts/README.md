# Scripts - InterHCE Ledger

Scripts de utilidad a nivel de proyecto:

- Despliegue coordinado (contratos + configuración backend/DApp).
- Simulación de múltiples IPS (Épica 6).
- Medición de tiempos, costos de transacción y generación de métricas para evaluación.
- Tareas de desarrollo (seed de datos, limpieza de entornos).

Los scripts de despliegue específicos de contratos pueden vivir en `contracts/scripts/`; aquí los que orquestan todo el sistema.
