# Código compartido - InterHCE Ledger

Artefactos compartidos entre backend, DApp y/o contratos:

- **Modelo HCE**: esquemas (JSON Schema), tipos TypeScript, constantes de campos obligatorios/opcionales.
- **Utilidades**: cálculo de hashes (SHA-256), formateo de datos para interoperabilidad.
- **Tipos**: interfaces comunes (episodio, metadatos, permisos) para frontend y backend.

Facilita consistencia en validación y representación de la HCE en todos los componentes.
